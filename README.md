# Turbo Flow — Promoción en Español

Página de marketing en español para [Turbo Flow v4.0](https://github.com/marcuspat/turbo-flow), el entorno de desarrollo agéntico con 600+ subagentes de IA y la migración a Ruflo.

## Secciones de la página

- **Hero** — titular y CTA principal para Turbo Flow v4.0
- **Problema / Solución** — puntos de dolor del desarrollador y cómo Turbo Flow los resuelve
- **ROI** — retorno de inversión y métricas de productividad
- **Testimonios** — feedback de la comunidad
- **CTA** — conversión y onboarding

## Stack tecnológico

- **Frontend:** Vite + React + TypeScript + Tailwind CSS + shadcn/ui
- **Despliegue:** Vercel

## Desarrollo local

```bash
npm install
npm run dev
```

Abrir [http://localhost:5173](http://localhost:5173).
